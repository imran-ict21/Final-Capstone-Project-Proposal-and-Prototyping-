# Project Schedule, Milestones, and Deliverables

**Planning assumption:** The timeline below is an illustrative 8-week plan for the full capstone after approval. Adjust start dates and durations to match the actual course calendar. The assignment's immediate submission deliverables should be completed first.

## Task schedule

| ID | Task | Duration | Dependency | Deliverable |
|---|---|---:|---|---|
| T1 | Confirm problem, scope, stakeholders, assumptions | 2 days | None | Scope statement |
| T2 | Gather and prioritize functional/non-functional requirements | 3 days | T1 | Requirements baseline |
| T3 | Write proposal and define acceptance criteria | 3 days | T2 | Proposal v1 |
| T4 | Select process model and prepare work plan | 1 day | T2 | Process-model section |
| T5 | Create DFD, Use Case, Activity, ER, Class, Object diagrams | 4 days | T2 | Six diagram sources |
| T6 | Design prototype screens and navigation | 2 days | T2 | UI sketch / layout |
| T7 | Implement domain model and sample data | 2 days | T6 | Domain classes |
| T8 | Implement dashboard and transaction form | 3 days | T7 | Prototype increment 1 |
| T9 | Implement calendar and daily transaction view | 3 days | T8 | Prototype increment 2 |
| T10 | Add input validation and CSV export | 2 days | T8 | Prototype increment 3 |
| T11 | Add MySQL schema and persistence | 4 days | T7 | Database-backed core |
| T12 | Add authentication and user-scoped authorization | 4 days | T11 | Secure account flow |
| T13 | Add filters and reporting / XLSX export | 3 days | T11 | Reporting increment |
| T14 | Unit, integration, acceptance, and regression testing | 4 days | T8–T13 | Test report |
| T15 | Review diagrams and update documentation | 2 days | T14 | Final docs |
| T16 | Capture screenshots, clean GitHub repository, final submission | 2 days | T15 | Submission package |

## Milestones
- **M1 — Requirements baseline:** T1–T2 completed.
- **M2 — Proposal and design approved:** T3–T6 completed.
- **M3 — Prototype demonstrated:** T7–T10 completed.
- **M4 — Persistent core ready:** T11–T12 completed.
- **M5 — Reporting ready:** T13 completed.
- **M6 — Final release candidate:** T14–T16 completed.

## Deliverables
1. Project proposal and requirements baseline.
2. Process-model justification.
3. Schedule, milestone and deliverable register.
4. Gantt chart.
5. Six system diagrams.
6. Prototype source code and setup guide.
7. Test cases/results and screenshots (to be completed after local execution).
8. GitHub repository and final submission URL.

## Schedule control
At the end of each increment, compare completed work with the plan. If a task slips, protect the core scope first: transaction recording, balance calculation, calendar/day view, persistence, and basic reporting. Defer optional features rather than sacrificing validation and testing.
