# Assignment Requirement Mapping

| Assignment requirement | Included deliverable | Location / verification |
|---|---|---|
| Project idea and proposal | Project overview, problem, objectives, scope, requirements, risks, testing, expected outcomes | `PROPOSAL.md` |
| Software process model | Iterative and incremental model with justification and review loop | `PROPOSAL.md` §8 |
| Completion schedule | Tasks, durations, dependencies, milestone and deliverable table | `planning/PROJECT_SCHEDULE.md` |
| Gantt chart | Mermaid Gantt source | `planning/GANTT.mmd` |
| Data Flow Diagram | Context and Level 1 DFD | `diagrams/DFD.mmd` |
| Use Case Diagram | Actors and major use cases | `diagrams/USE_CASE.mmd` |
| Activity Diagram | Record transaction workflow | `diagrams/ACTIVITY.mmd` |
| Entity Relationship Diagram | User, Wallet, Category, Transaction entities and cardinalities | `diagrams/ERD.mmd` |
| Class Diagram | Core domain, service, repository, and controller classes | `diagrams/CLASS_DIAGRAM.puml` |
| Object Diagram | Example runtime objects for one user's transactions | `diagrams/OBJECT_DIAGRAM.puml` |
| Interface using at least five classes | Web prototype uses `Transaction`, `Income`, `Expense`, `WalletService`, `TransactionService`, `DashboardService`, `CalendarService`, `HomeController` | `prototype/src/main/java/...` and `templates/index.html` |
| GitHub link | Repository-ready files and README | Upload folder contents to GitHub; add actual URL to LMS |

**Submission caution:** grading rubrics differ. Confirm whether your instructor expects diagrams embedded in the proposal, a PDF export, screenshots, or a live prototype URL. The source files are included so the diagrams can be rendered and revised.
